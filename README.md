# Function Header Template
Copy and paste this template above your functions:

```kotlin
/**
 * [Function Name]
 *
 * Description: Briefly describe what this function does.
 *
 * @param param1 Description of the first parameter.
 * @param param2 Description of the second parameter.
 * @return Description of what the function returns.
 * @throws ExceptionType (if applicable) Description of when an exception might occur.
 *
 * Example Usage:
 * ```
 * val result = functionName(arg1, arg2)
 * ```
 */
```
